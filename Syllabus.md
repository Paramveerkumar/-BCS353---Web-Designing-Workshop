# 🌐 BCS353 - Web Designing Workshop

## 📚 Course Syllabus

This repository contains study materials, programs, practical examples, and projects related to **BCS353 - Web Designing Workshop**.

The course covers:

- HTML
- CSS
- Responsive Web Design
- Bootstrap
- UI Design
- JavaScript
- Intermediate JavaScript

---

# 📖 Course Content

## 🧱 UNIT 1: HTML

HTML (**HyperText Markup Language**) is used to create the structure of web pages.

### Topics Covered

- HTML Elements
- HTML Attributes
- HTML Headings
- HTML Paragraphs
- HTML Styles
- HTML Comments
- HTML Links
- HTML Images
- HTML Favicon
- HTML Tables
- HTML Lists
- HTML Class
- HTML ID
- HTML Forms
- HTML Media
- HTML Navigation Bar

---

# 🎨 UNIT 2: CSS

CSS (**Cascading Style Sheets**) is used to design and style web pages.

### Topics Covered

- Types of CSS
  - Inline CSS
  - Internal CSS
  - External CSS
- CSS Colors
- CSS Background
- CSS Margins
- CSS Padding
- CSS Height
- CSS Width
- CSS Text
- CSS Font
- CSS Icons
- CSS Links
- CSS Lists
- CSS Tables
- CSS Display
- CSS Z-Index
- CSS Float
- CSS Overflow
- CSS Media Queries
- Inline and Block Elements
- CSS Navigation Bar
- CSS Image Gallery
- CSS Forms
- CSS Rounded Corners

---

# 📱 UNIT 3: BOOTSTRAP & RESPONSIVE WEB DESIGN

Bootstrap is used to create responsive and mobile-friendly websites.

### Topics Covered

- Fundamentals of Implementing Responsive Web Design
- Using Balsamiq to Mockup and Wireframe Websites
- Fundamentals of UI Design for Websites
- How to Install the Bootstrap Framework
- Understanding the Bootstrap Grid Layout System
- Bootstrap Containers
- Bootstrap Buttons
- Adding Symbols using Font Awesome
- Bootstrap Carousels
- Bootstrap Cards
- Bootstrap Navigation Bars

---

# ⚡ UNIT 4: JAVASCRIPT FUNDAMENTALS

JavaScript is used to make websites interactive and dynamic.

### Topics Covered

- JavaScript Script
- Functions
- Output
- Statements
- Variables
- Operators
- Data Types
- Objects
- Events
- String Methods
- Arrays
- If-Else
- Switch
- For Loop
- For-In Loop
- Debugging
- Form Validation
- Functions and Invocation Patterns

# 🚀 UNIT 5: INTERMEDIATE JAVASCRIPT

This unit covers advanced JavaScript programming concepts.

### Topics Covered

- Discussion of ECMAScript
- Intermediate JavaScript
- JavaScript Expressions
- Operators
- Statements
- Declarations
- Object-Oriented Programming
- JavaScript Objects
- Prototypes
- `this` Keyword
- Scope
- Closures
- Objects and Prototypes
- Refactoring
- Debugging
