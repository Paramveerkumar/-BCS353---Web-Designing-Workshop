## Experiment 1: Online Book Store Website

### Aim

Design the following static webpages required for an **Online Book Store Website**.

### 🏠 HOME PAGE

The static home page must contain **three frames**.

#### Top Frame

The top frame should contain:

* Logo
* College Name
* Links to:

  * Home Page
  * Login Page
  * Registration Page
  * Catalogue Page
  * Cart Page

#### Left Frame

The left frame should contain links for different book categories, such as:

* CSE
* EEE
* CIVIL

For example:

> When the user clicks on the **CSE** link, the catalogue for **CSE Books** should be displayed in the right frame.

#### Right Frame

The pages corresponding to the links in the left frame must be loaded in the **Right Frame**.

Initially, this page should contain a description of the website.

### Concepts Used

* HTML Frames
* Links
* Images
* Navigation
* HTML Pages

## Experiment 6: JavaScript Validation – Name and Password

### Aim

Write JavaScript to validate the following fields of the Registration Page.

### Validation Rules

#### Name

* Name should contain alphabets.
* The length should not be less than **6 characters**.

#### Password

* Password should not be less than **6 characters** in length.

### Concepts Used

* JavaScript
* Conditional Statements
* Form Validation
