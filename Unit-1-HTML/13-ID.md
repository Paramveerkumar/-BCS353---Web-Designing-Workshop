# 🆔 HTML `id` Attribute

## 📌 Introduction

The HTML `id` attribute is used to give a **unique identification name** to an HTML element.

Unlike the `class` attribute, an `id` should be used for **only one element** on a webpage.

### Example

```html
<h1 id="myHeader">Welcome to My Website</h1>
```

Here:

* `id` → Attribute name
* `"myHeader"` → Unique ID name

---

# 1️⃣ What is the `id` Attribute?

The `id` attribute specifies a **unique identifier** for an HTML element.

### Important Rule

⚠️ **Two elements should not have the same `id` value in the same HTML document.**

❌ Incorrect:

```html
<h1 id="heading">Welcome</h1>

<p id="heading">Hello Students</p>
```

Both elements use the same ID, which is not correct.

✅ Correct:

```html
<h1 id="heading">Welcome</h1>

<p id="paragraph">Hello Students</p>
```

Each element has its own unique ID.

---

# 2️⃣ Using `id` with CSS

The `id` attribute is commonly used to apply a specific CSS style to one particular element.

In CSS, an ID selector starts with a **hash symbol (`#`)**.

### HTML

```html
<h1 id="myHeader">My Header</h1>
```

### CSS

```css
#myHeader {
    background-color: lightblue;
    color: black;
    padding: 40px;
    text-align: center;
}
```

---

# 3️⃣ Complete Example

```html
<!DOCTYPE html>
<html>

<head>

    <title>HTML ID Attribute</title>

    <style>

        #myHeader {
            background-color: lightblue;
            color: black;
            padding: 40px;
            text-align: center;
        }

    </style>

</head>

<body>

    <h1 id="myHeader">My Header</h1>

</body>

</html>
```

### 📝 Explanation

The HTML element has:

```html
id="myHeader"
```

The CSS uses:

```css
#myHeader
```

The `#` symbol tells CSS that `myHeader` is an **ID selector**.

---

# 🧠 Easy Way to Remember

Think about an `id` like a **roll number or unique identity**.

For example:

```text
Student Name: Rahul
Roll Number: 101
```

The roll number uniquely identifies one student.

Similarly:

```html
<h1 id="myHeader">Welcome</h1>
```

The ID `myHeader` uniquely identifies that particular element.

---

# 4️⃣ Rules for Using an `id`

When creating an ID name, remember these important rules:

### ✅ Rule 1: ID should be unique

An ID should identify only one element on the page.

```html
<h1 id="header">Welcome</h1>
```

---

### ✅ Rule 2: ID names are case-sensitive

These are considered different:

```html
id="header"
```

and:

```html
id="Header"
```

⚠️ However, it is better to use consistent lowercase names.

### Recommended:

```html
id="main-header"
```

```html
id="student-details"
```

```html
id="contact-section"
```

---

### ✅ Rule 3: Do not use spaces in an ID name

❌ Incorrect:

```html
<h1 id="main header">Welcome</h1>
```

✅ Correct:

```html
<h1 id="main-header">Welcome</h1>
```

or:

```html
<h1 id="mainHeader">Welcome</h1>
```

---

# 5️⃣ Difference Between `class` and `id`

This is one of the most important concepts in HTML and CSS.

| Feature          | `class`           | `id`               |
| ---------------- | ----------------- | ------------------ |
| Used for         | Multiple elements | One unique element |
| CSS symbol       | `.` (dot)         | `#` (hash)         |
| Can be repeated? | ✅ Yes             | ❌ No               |
| Example          | `.city`           | `#header`          |
| HTML syntax      | `class="city"`    | `id="header"`      |

---

# 6️⃣ Example: `class` vs `id`

```html
<!DOCTYPE html>
<html>

<head>

    <title>Class and ID Example</title>

    <style>

        /* Style one unique element using ID */

        #myHeader {
            background-color: lightblue;
            color: black;
            padding: 40px;
            text-align: center;
        }


        /* Style multiple elements using Class */

        .city {
            background-color: tomato;
            color: white;
            padding: 10px;
            margin: 10px;
        }

    </style>

</head>

<body>

    <!-- Unique element using ID -->

    <h1 id="myHeader">My Cities</h1>


    <!-- Multiple elements using the same Class -->

    <h2 class="city">London</h2>
    <p>London is the capital of England.</p>

    <h2 class="city">Paris</h2>
    <p>Paris is the capital of France.</p>

    <h2 class="city">Tokyo</h2>
    <p>Tokyo is the capital of Japan.</p>

</body>

</html>
```

---

# 🔍 Understanding the Example

The heading:

```html
<h1 id="myHeader">My Cities</h1>
```

uses a unique ID:

```css
#myHeader
```

Therefore, this style applies only to that specific heading.

---

The city headings use:

```html
class="city"
```

Therefore, the same CSS style:

```css
.city {
    background-color: tomato;
}
```

is applied to all elements having the `city` class.

# 7️⃣ Using `id` with JavaScript

The `id` attribute is also useful in JavaScript.

JavaScript can access an element using its ID with:

```javascript
document.getElementById()
```

### Example

```html
<!DOCTYPE html>
<html>

<body>

    <h1 id="heading">Hello Students!</h1>

    <button onclick="changeText()">
        Click Me
    </button>

    <script>

        function changeText() {

            document.getElementById("heading").innerHTML =
            "Welcome to HTML!";

        }

    </script>

</body>

</html>
```

### 📝 What happens?

Initially:

```text
Hello Students!
```

When the user clicks the button:

```text
Click Me
```

JavaScript finds the element with:

```html
id="heading"
```

and changes its content to:

```text
Welcome to HTML!
```

# 🆚 Quick Comparison

## `class`

Use `class` when you want to apply the same style to **multiple elements**.

```html
<h2 class="student">Rahul</h2>
<h2 class="student">Priya</h2>
<h2 class="student">Amit</h2>
```

---

## `id`

Use `id` when you want to identify **one specific element**.

```html
<h1 id="main-heading">
    Student Information
</h1>
```

---

# 🧠 Simple Formula to Remember

```text
class → Many Elements → .
```

```text
id → One Unique Element → #
```

### Example

```text
HTML                     CSS

class="city"      →      .city

id="header"       →      #header
```

# 🎯 Chapter Summary

* The HTML `id` attribute gives a **unique identity** to an element.
* An ID should be unique within a webpage.
* CSS uses the `#` symbol to select an ID.
* Classes use the `.` symbol in CSS.
* `class` can be used by multiple elements.
* `id` is used to identify one specific element.
* ID names are case-sensitive.
* Avoid spaces in ID names.
* JavaScript can access an element using:

```javascript
document.getElementById()
```
